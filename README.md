# gubby

a multitool desktop app with 21 tools and a bouncing gubby lolll

## install

double-click **`gubby-installer.exe`** — it will:
1. check if python is installed (downloads it if not)
2. install PyQt6, qrcode, Pillow
3. launch gubby

## run from source

```
python gubby.py
```

requires: python 3.10+, PyQt6, qrcode, Pillow

## tools

**text:** text diff, base64, url encode/decode, json formatter, markdown preview, word counter, lorem ipsum, password generator, uuid generator  
**media:** color picker, image to base64, qr code generator  
**network:** ip lookup, http request tester, port scanner, dns lookup  
**misc:** pomodoro timer, stopwatch, unit converter, notepad, ascii art
